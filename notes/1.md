## Приветственная страница: 
Когда на сайт заходит не зарегестирированный пользователь, у него выскакивает страница такого содержания 
1. Предложение войти или зарегестрироватся
2. Прессеты заметок - для тем и лучшего понимания как писать заметки
общий топ заметок - которые больше всего сохранили к себе.

## Смена темы: выбор темы на основе написанного в заметке

**Как выглядит** 
1. Пользователь выбирает темную, розовую, свою тему
2. При нажатии на своя тема, пользователю предлагают выбрать заметку в качестве настройки темы

Заметка с настройками темы примерно такого вида:
```
Цвет фона: FFFFFF
Цвет заголовков: FFFFFF
Цвет обычного текста: FFFFFF
Шрифт: "comic sans"
```
использование прессетов цвета:
```
Цвет фона: БЕЛЫЙ (аналог FFFFFF)
Цвет заголовков: БЕЛЫЙ
```
прессеты описываются сверху в этом же файле по схеме
```
БЕЛЫЙ = FFFFFF
ЧЕРНЫЙ = 000000
```
